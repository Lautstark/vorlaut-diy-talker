The board as a document, in a real browser

static/obf.js and the two ends of it in static/backend/local.js: a board out as a .obz, the same file back in, and every set, key, symbol reference and the language compared. tests/test_obf_js.py runs the same converter under node against obf.py; what only a browser can answer is the part below it - CompressionStream, the store the layout really comes out of, and the download the settings sheet really makes.

Must be served from the app's own origin, so that /static/ and the import map resolve: run the interface, then open this file's contents there. It writes into the same IndexedDB the page uses and puts back what it found.
