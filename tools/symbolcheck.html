The fallback

The one that will not fail here by accident. When an image fetch fails, bildquelle hands back ARASAAC's own URL so the <img> can still try — and a canvas drawn from a cross-origin image is tainted, so getImageData throws and a tile fails at build time after looking right on screen. This forces that path instead of waiting for a bad network.
