# Pillow draws the tile sheets the device reads (tiles.py) and the wiring
# diagram (tools/wiring.py). It is the only dependency here that renders
# pixels, and the only one a version bump can change the output of silently.
#
# The floor is what is installed and tested against. The ceiling is the next
# major, because that is where Pillow drops deprecated API - and this is an
# application that ships as an image built and pushed unattended, so an
# unbounded upgrade would land in a published image rather than in a test run
# somebody is watching. Patches and minors still come in: those are where the
# security fixes are, and Pillow decodes files that arrive from outside.
Pillow>=12.3,<13
